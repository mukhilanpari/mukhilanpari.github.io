I'm **Mukhilan Pari**, a software &amp; firmware security engineer. My work spans
product security — web, mobile, and low-level/firmware — and, increasingly, the
intersection of security with LLMs.

What I spend my time on:

- **Product security research** — offensive testing across web, mobile, and
  low-level targets in my day-to-day work.
- **Security research &amp; CTFs** — vulnerability analysis; I've played CTFs
  competitively and authored challenges for an international CTF.
- **LLM harnessing** — building agent harnesses that put language models to work
  on security tasks: fuzzing, vulnerability triage, and exploit-analysis workflows.
- **Local-model benchmarking** — benchmarking open-weight models running locally
  on security workloads, and publishing the results.

Earlier writeups (2019–2021) — OSCP-era lab writeups, mobile SSL-pinning research,
an MFA paper, and a CTF guest lecture — live in the [archive](/archive/).
